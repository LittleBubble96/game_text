# 微信小游戏包内资源

当前默认开启 `UnityProject/Assets/TEngine/Settings/UpdateSetting.asset` 中的 `WechatEmbedResources`。

使用 **TEngine → Build → 一键打包Webgl(Release)** 或 **一键打包Webgl(Develop)**。需要重新生成 Unity Player，不能仅替换旧导出的 JS、AB 或只重新转换旧 WebGL 文件。

构建仍然生成 YooAsset AssetBundle，随后将 DefaultPackage 的完整 AB、版本、清单和 hash 临时复制为 `Resources/EmbeddedYooAssets` 下的 TextAsset，嵌入 Unity 的 `.data` 首包。微信 SDK 用“小游戏包内”方式将首包数据作为资源分包发布，并不是把所有文件硬塞进小游戏启动主包。无需移动原始美术资源，也无需修改业务的异步加载调用。

运行时，微信 WebPlayMode 使用 EmbeddedResourceFileSystem：从包内读取版本及清单、验证清单，再按需异步读取 AB。此路径没有资源 CDN 请求，也不会回退读取远程最新清单。其他平台和编辑器模拟模式保持原流程。资源改变时，需要重新发布小游戏包。

构建结束后清理本次临时生成的 Resources 目录。构建中断导致目录残留时，下次构建会拒绝覆盖：先检查 `Assets/Resources/EmbeddedYooAssets` 确实是上次构建临时文件，再删除该目录重试。

关闭 `WechatEmbedResources` 后重新执行一键 WebGL 构建，即恢复原有 CDN 文件系统；构建入口会自动选择 CDN 首包加载方式。CDN 地址配置予以保留。

## 限制与验收

- 当前实现用于未加密的 AssetBundle；包内构建自动使用完整包、禁用最小包裁剪和 AB 加密。仅嵌入 DefaultPackage，增加其他资源包时需要扩展构建入口。
- 本地已安装的微信 SDK 按“压缩 WASM + 压缩 data”检查可用体积；若压缩失败或超出 SDK 阈值而回退 CDN，本构建入口会报错，不能把本次产物当成包内版本发布。平台实际上传限制以开发者工具校验为准。
- `.data` 会增大，首次启动需要下载完整资源，内存开销也高于微信原生按文件读取缓存的方案。适合当前小型游戏，资源持续增大后可切回 CDN。
- 首次获取小游戏代码、插件和资源仍需要网络。资源包内加载不保证微信宿主在所有情况下都能离线启动，也不让广告、微信登录和服务器功能离线可用。
- 重新导出后检查 `minigame` 内存在数据资源分包；真机联网完整进入，完全退出，再断网打开，验证首页、全部关卡、音效和存档。网络面板不应出现资源 `.version`、`.hash`、清单或 `.bundle` 的 CDN 请求。
- 本次已验证微信运行时及编辑器相关程序集可编译；尚未执行完整 Unity 导出或真机断网验收，最终包体和内存以新构建为准。
